## 🚀 在 Windows 上使用

### ▶️ 方法一：直接运行（推荐，无需装任何东西）

找有 Python 的朋友运行 **`build.bat`**，生成 `比格多栋.exe`，你拿到后 **双击就能用**！**不需要装 Python！**

### ▶️ 方法二：自己装 Python 运行

**第1步：安装 Python**
1. 打开 https://www.python.org/downloads/
2. 点击黄色 **Download Python 3.x**
3. 运行安装程序
4. **⚠️ 必须勾选 "Add Python to PATH"**
5. 点 Install Now，等2分钟装完

**第2步：启动比格多栋**
1. 解压本文件夹
2. 双击 **`一键启动.bat`**
3. 它会自动安装 PyQt5（首次需联网）
4. 比格多栋出现在屏幕上！🎉

### ▶️ 方法三：自己打包成 EXE

1. 确保已装 Python
2. 双击 **`build.bat`**
3. 等 1-3 分钟
4. 在 `dist\比格多栋_v1.0\` 找到 `比格多栋.exe`
5. 发给朋友，双击即用！
